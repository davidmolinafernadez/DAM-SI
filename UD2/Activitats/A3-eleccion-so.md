## Producto final

PDF de 3-5 páginas llamado `Tarea_2_3_Apellidos_Nombre.pdf`.

## Caso

Elige uno:

- aula de 30 puestos para 1.º DAM;
- portátil personal para desarrollar Java, bases de datos y aplicaciones web;
- servidor web de una pequeña empresa;
- puesto de diseño audiovisual;
- dispositivo empotrado o IoT.

Compara al menos tres opciones: Windows, una distribución GNU/Linux y otra
alternativa razonable para el caso.

## Fase 2 · Matriz ponderada

Asigna pesos de 1 a 5 y puntúa cada sistema de 1 a 5.

| Criterio | Peso | Opción A | Opción B | Opción C |
|---|---:|---:|---:|---:|
| Compatibilidad |  |  |  |  |
| Soporte |  |  |  |  |
| Seguridad |  |  |  |  |
| Administración |  |  |  |  |
| Coste total |  |  |  |  |
| Rendimiento |  |  |  |  |
| **Total ponderado** |  |  |  |  |

Calcula cada puntuación como `peso × valoración` y suma el total ponderado.
Después explica qué criterio ha decidido más. Si la opción con más puntos no es
la elegida, justifica por qué: puede haber un requisito obligatorio que pese más
que la suma.

## Fase 3 · Licencia y ciclo de soporte

Incluye una comparación breve de licencias y soporte. Debes citar, como mínimo,
una fuente oficial del fabricante o comunidad para cada opción finalista.

## Fase 4 · Decisión

Redacta una recomendación de 12-18 líneas. Incluye riesgos, condiciones y una
prueba piloto que harías antes de implantar.

## Evidencias mínimas

Incluye:

- tres opciones comparadas con nombre y versión o edición aproximada;
- al menos una fuente oficial por opción finalista;
- una matriz con pesos y total calculado;
- una decisión final con riesgos y prueba piloto.
