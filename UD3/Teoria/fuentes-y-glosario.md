# UD3 · Fuentes y glosario

## Vocabulario de trabajo

| Término | Sentido en esta unidad |
| --- | --- |
| Interfaz | Punto de conexión físico o virtual de un equipo |
| Trama | Unidad de datos de enlace |
| Paquete | Unidad de datos IP |
| MAC | Dirección de enlace; no indica en qué red IP está un equipo |
| Prefijo | Cantidad de bits de red en una dirección |
| Máscara | Representación IPv4 del límite entre red y host |
| Broadcast | Envío a todos los participantes del dominio correspondiente |
| Subred | Bloque identificado por dirección de red y prefijo |
| Puerta de enlace | Siguiente salto hacia destinos fuera de las rutas locales aplicables |
| DHCP | Protocolo para obtener parámetros de configuración |
| DNS | Sistema distribuido para resolver nombres y otros datos |
| CIDR | Direccionamiento y agregación mediante prefijos explícitos |
| VLSM | Uso de subredes con prefijos de longitudes distintas |
| NAT | Traducción de direcciones; su comportamiento depende del modo configurado |

## Orientación para las evidencias

Anota la versión del sistema o de la herramienta que realmente utilizas. Diferencia dato observado, hipótesis y conclusión. Una captura o un resultado calculado necesitan explicación y referencia al requisito que comprueban.
