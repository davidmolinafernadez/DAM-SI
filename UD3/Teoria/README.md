# UD3 · Instalación de sistemas y virtualización

Sistemas Informáticos · 1.º DAM

Una unidad de laboratorio: cada explicación conduce a una decisión, una práctica y una prueba que demuestra el resultado. Aprenderás a instalar Ubuntu y Windows, organizar discos, conectar una web, actualizar, recuperar y transportar máquinas virtuales.

    36 horas de clase, con 25,5 horas de prácticas principales. Arranque dual y Docker añaden cinco horas opcionales. Los tiempos se adaptarán a los puestos del aula.

## Cómo trabajar

1. Lee el bloque relacionado y escribe una predicción.
2. Ejecuta la práctica sobre la VM y el disco indicados.
3. Comprueba el resultado y explica la evidencia.
4. Si algo falla, registra síntoma, hipótesis, prueba y corrección.

Vas a construir un laboratorio que permita instalar, comprobar, estropear de forma controlada y recuperar sistemas operativos. El objetivo profesional es entregar un equipo que otra persona pueda utilizar y mantener. Llegar al escritorio es un paso intermedio: faltan actualizaciones, comprobación de dispositivos, conectividad, protección de datos y documentación.

La unidad se organiza en doce bloques. Cada bloque termina con una actividad breve y remite a una práctica del cuaderno 02. Antes de ejecutar una instrucción, di qué esperas observar; después compara el resultado real con esa predicción. Un resultado inesperado es una oportunidad para diagnosticar, siempre que conserves un estado recuperable.

Laboratorio de referencia: anfitrión x86-64, VirtualBox de la rama estable aprobada por el centro, Ubuntu Desktop 24.04 LTS y Windows 11 de la edición autorizada. Ubuntu 24.04 se mantiene como referencia para aprovechar los materiales previos; no se presenta como la LTS más reciente. Registra las versiones exactas utilizadas. Los nombres y el orden de algunas pantallas cambian entre versiones.
