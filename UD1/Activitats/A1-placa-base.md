## Fase 3 · Razona

1. ¿Qué tres componentes cambiarías para convertir un PC de oficina en una
   estación adecuada para desarrollar aplicaciones y usar máquinas virtuales?
2. ¿Por qué no debes memorizar la posición exacta de los conectores?
3. Localiza en el manual de una placa real el diagrama de componentes. Añade
   modelo, URL, página y fecha de consulta.
4. Señala dos errores de montaje que podrían impedir el arranque.
