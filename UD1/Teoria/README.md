## Pregunta conductora

> ¿Por qué dos ordenadores con componentes aparentemente parecidos pueden tener rendimientos, compatibilidad y fiabilidad muy diferentes?

Al terminar, el alumnado debe poder justificar una configuración completa, detectar incompatibilidades antes del montaje y explicar con precisión cómo ejecuta instrucciones un ordenador.
